# Student Performance Analysis 📊

## 📌 Overview
This project was completed as part of the DecodeLabs Data Science Internship.

The project focuses on:
- Dataset Understanding
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)

## 🛠 Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Dataset Used
Student Performance Dataset

## 📊 Tasks Completed

### ✅ Task 1: Dataset Understanding
- Loaded dataset
- Identified columns and data types
- Analyzed dataset structure

### ✅ Task 2: Data Cleaning & Preprocessing
- Removed duplicates
- Checked missing values
- Standardized column names
- Saved cleaned dataset

### ✅ Task 3: Exploratory Data Analysis (EDA)
- Performed statistical analysis
- Created graphs and visualizations
- Identified trends and patterns

## 📈 Key Insights
- Female students performed better in reading and writing.
- Reading and writing scores are strongly correlated.
- Most students scored between 50–80 marks.
